# YH 0.32.0 / OYSM HCD 0.2.0 解耦

本轮把模型供应商的内部实现收回 OYSM。YH 保留角色资产、战斗信号、服务端表现请求、
表现信号和脚本入口；通用模型 editor、preset、预览和目录全部由 OYSM 持有。
OYSM 的 `oysm-hcdrs` 从兼容分支建立，未合入 standalone 的 `54a8286` 缓存导出提交。

| 责任 | 最终位置 |
| --- | --- |
| 模型包资源发现、缓存、客户端同步 | OYSM `ExternalModelPackAPI` / `ServerModelManager` |
| 模型、转盘、控件、弹射物槽目录 | OYSM `ExternalLivingPresentationAPI` |
| 外部生物渲染、重播、时钟修复、数值租约与恢复 | OYSM 公开 API 与原生渲染器 |
| 手持物渲染、原生玩家动画提示入口 | OYSM 原生层 / `PlayerPresentationAPI` |
| YH 弹幕的渲染代理、朝向和颜色策略 | YH `YsmProjectileRenderBridge`，调用 OYSM 公开弹射物 API |
| 蕾米莉亚资产、默认 preset 输入、符卡信号和业务场景 | YH |
| preset ID 生成、保存、编辑、预览和同步 | OYSM |

## 资源与兼容

蕾米莉亚资源仅由 YH 的 `assets/youkaishomecoming/models/ysm/remilia/` 分发。
YH 通过 OYSM 的 `ExternalModelPackAPI` 注册 `youkaishomecoming/` 模型入口；
YH 使用 `youkaishomecoming/remilia/...` 资源路径，不声明 `YH内置` 路径或旧 ID 别名。
删除 `YsmModelPackInstaller`；启动时不再向 `config/yes_steve_model/custom/` 复制资源。
OYSM 的第三方模型走既有服务端缓存和同步链路；它也自动发现其他模组的
`assets/<modid>/ysm_models/`。

旧 custom 目录不参与 YH 的资源注册；需要使用随 YH 更新的资源时，应清理旧副本。

YH 编译需要对应 OYSM API JAR，运行时 OYSM 仍为可选依赖。
`YsmOpenYsmSupport` 仅检查公开 common API 是否存在，不反射供应商内部类。
common 资源注册入口为隔离可选依赖，保留对 `ExternalModelPackAPI.registerDirectory` 一个公开方法的反射调用；客户端渲染与表现接口直接调用。
缺失或旧版 OYSM 没有该 API 时跳过这条兼容路径；YH 原生渲染仍可用。
删除了手持物和玩家提示两个 OYSM mixin，运行路径不访问 OYSM 私有缓存、控制器或变量存储。
YH 不再包含 `YsmModelProfile`、`YsmProfileData`、`format=1` 或通用 YSM editor 类；
YH 将注册返回的不可变绑定映射交给业务信号路由；不拼接 preset ID 或保存 namespace 规则。

## 验证与发布验收

OYSM common/Forge 构建、数值恢复/时钟/玩家提示/JAR 资源注册契约，以及 YH
主源码编译和静态契约搜索用于本轮验证。数值存储和动画时钟测试已从 YH 删除，
待 OYSM 原生 API 测试补齐后在 OYSM 验证。

这些检查不替代实机验收。发布前需要核对：从 YH JAR 加载蕾米莉亚、
服务器模型同步、战败三相位与治疗恢复、主副手位置、玩家符卡动画提示，以及预览滑条后的
保存/捕获。无 OYSM 与无 TLM 启动也需游戏环境验收。
