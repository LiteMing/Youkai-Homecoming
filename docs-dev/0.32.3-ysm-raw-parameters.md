# 0.32.3：无表单模型的参数选择

配套 OYSM HCD 0.2.3。`/yhysm editor` 的参数候选原来仅来自作者配置表单及已保存的参数，
使旧模型或没有配置表单的模型即使读取 `v.xxx`，也无法在下拉列表选取。

YH 现在读取 OYSM 的公开 `parameterNames(modelPath)`，在“参数”目录和预设的“参数”／
“高级”页提供变量名与数值输入。作者已有控件保持原来的标签、范围和选项；参数目录可切换
“原始变量”，编辑绑定外观或当前预设。未初始化的值留空，可手工输入，不虚构成 0。
旧版 OYSM 仍显示已有表单与手工输入；没有 OYSM 时继续按原有缺失状态降级。

变量目录由 OYSM 解析所选入口的动画与控制器，YH 不读取其内部缓存或变量池。
原始变量可能被模型动画重写，也可能不是数值；本补丁不把全部动画中间变量自动捕获为预设。
只有作者表单输入和用户明确覆盖的参数沿用现有预设保存、同步和到期恢复链路。

实测目标 `touhou/reimu2.0.5.ysm/main`：旧格式 1，无表单；变量为 `v.jump`、`v.qh`、
`v.qh2`、`v.random`。OYSM 同时修复旧转盘标签丢失与旧缓存复用问题，预期能选到
指指点点、bad！、大大大！、梦想封印、喝茶、摇御币 6 个动作。

交付检查覆盖旧格式解析/现代缓存往返、不同几何入口的变量隔离、无表单目录及公开 API。
构建和目录诊断不代替实机鼠标操作与外观验证。重启整合包后应核对上述动作与参数下拉、
调整 `v.qh`、保存/恢复预设，并确认动画自行重写参数时的实际表现。

构建记录：compileJava、organizeLang、jarJar/reobf/refmap 检查通过；251 项无 OYSM 契约，
262 项生产 OYSM 接口契约通过。OYSM 78 项契约及 Forge 构建通过，源模型目录诊断得到
上述 4 个变量和 6 个动作。当前没有实机鼠标交互的通过记录。
