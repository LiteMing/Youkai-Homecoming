# 0.26.3：弹幕回调上下文与编辑器交互修复

本版本围绕真实世界激光碰撞、回调变量和 Viewport 编辑操作收敛语义。Preview 与服务端
必须使用同一份回调快照和处置规则；编辑器的树路径、坐标和下拉索引也必须保持一致。

## 修复范围

1. **统一激光命中上下文与处置**
   - 激光 block/entity 命中都通过 `SpellHitContext.laserHit(...)` 创建上下文。
   - `continue_source` 保留激光并穿透方块，`discard_source` 只移除弹幕且不触发 `on_expiry`，
     `expire_source` 运行一次 expiry 后移除。
   - Bounce/Hold 仍是点弹幕专用，激光不会误进入点弹幕状态机。

2. **固定 callback 快照语义**
   - `position` / `source_hook_x/y/z` 是本次回调点（旧 `hook_*`/`hookpos_*` 仍兼容）；
     `source_position_*` 是弹幕锚点。
   - `source_velocity_*`、`source_direction_*`、`source_speed`、大小、扩散、寿命、年龄、
     颜色都来自发射时快照。
   - 激光 `start_*`、`source_end_*`、`source_clipped_end_*` 在命中转 expiry 时保留命中瞬间的几何值。
     开发期直接移除旧 `end_*` / `laser_end_*` 与 `clipped_end_*` / `laser_clipped_end_*`，
     不保留兼容分支。
   - `on_hit_entity` / `on_hit_block` 每个激光实例只在第一次实际命中时触发一次；
     `on_trail` 才是按 `trail_interval` 周期执行的飞行中回调。
     Preview 与实机共用激光实例级 gate，重复重叠不会重新执行 on-hit。
   - `NumberExprParser` 允许在任意数值编辑框手动输入这些变量或组合表达式；不再提供
     单独的 callback-origin 选择器。需要以回调点为原点时使用 `origin.mode=world` 搭配
     `source_hook_x/source_hook_y/source_hook_z`。

3. **Target facing 与 Viewport 同步**
   - 新增 `target_facing` aim mode 及 `target_facing_x/y/z` 表达式。
   - 透视视角绑定目标时，每 tick 将相机位置与视线写入 Preview target；真实世界使用
     目标实体的服务端视线。
   - Origin 模式明确区分 caster/target 世界轴、caster/target facing 局部轴和绝对世界坐标。

4. **ActionPath 与 Edit Origin**
   - ActionPath 遍历完整动作树，包含折叠的 callback 子节点；弹幕和激光都携带来源路径，
     选择不会因折叠、重排或同叶索引而串项。
   - 暂停预览后可在选中弹幕附近的坐标轴旁点击 `Move Origin`，拖动只更新暂停帧；
     `Apply` 写入一次 undo 快照，`Cancel` 恢复原动作。播放中不会误触发重播。
   - Viewport 支持选中弹幕、激光或发射器组绕 X/Y/Z 旋转；激光旋转以逻辑 beam start 为轴心。

5. **回调编辑器与下拉框**
   - 数值输入统一使用表达式编辑框，支持函数、变量和 callback 字段补全；空前缀补全按
     `source_...`、`target_...` 等目录折叠，输入前缀后直接筛选具体字段。
   - 枚举、字符串和表达式弹层共享同一坐标计算，支持向上展开、滚动和滚动条点击；
     绘制索引与鼠标索引都加上相同的 scroll offset，避免选中最后一项或错位。
   - `run_command` 继续交给原版 `CommandSuggestions`，其弹层位置会在编辑器底部空间不足时
     自动向上偏移。

## 自动验证

- `runBounceSurfaceResponseTest`：77 项通过，覆盖激光/点弹幕处置、Hold 延迟释放、
  Last Writer Wins、反弹上限和异常加速度重建。
- `runSpellCallbackContractTest`：44 项通过，覆盖激光几何快照、callback 表达式字段、
  延迟快照、ActionPath 深层枚举、Origin 逆变换和组旋转正交性。
- `compileJava`：通过。

以上测试是窄契约测试，不能替代装载 OYSM/TLM 的客户端实机验收。发布前仍需在暂停和播放
两种状态分别验证 Origin 拖动、透视 target facing、激光 clipped-end 回调和下拉框点击。
