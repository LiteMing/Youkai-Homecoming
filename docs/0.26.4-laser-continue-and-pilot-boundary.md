# 0.26.4 激光 CONTINUE 与 Pilot 场地边界修复

## 激光 CONTINUE

`CONTINUE` 的语义恢复为既有的穿透行为。激光只有在确实需要 block 命中处理时才进行方块探测：

- `hit_behavior_block: "continue"` 且没有 `on_hit_block` 节点时，发射端保持 `bypassWall=true`，
  服务端与 Preview 都不搜索 clipped end；
- `on_hit_block` 有实际节点时，第一次方块命中仍需探测并提供 callback 的 `source_hook_xyz`、
  `source_clipped_end_xyz` 等上下文；
- callback 最终写入 `continue_source` 后，激光恢复完整长度并停止后续墙面探测；
- `discard` / `expire` 仍按原有规则保留墙前前缀，分别抑制或触发 expiry。

显式空数组 `on_hit_block: []` 等同于没有 hook，不会仅因为 Optional 存在而启用 clip 探测或
被分析器计为命中 hook。

## Pilot 场地边界

Pilot 的碰撞约束现在同时检查候选终点和从当前包围盒到终点的完整扫掠路径。这样高速候选不能
从方块一侧跳到另一侧再被当作可行路径。搜索扩展、APF 输出收口、客户端玩家执行和服务端妖怪
执行都经过同一 `CollisionOracle.isPathFree` 约束；Preview 的 `ALWAYS_FREE` 仍保持无世界碰撞
的编辑器语义。
