# 0.29.2：宣言冻结与符卡 hint

## 定时无敌与冻结 onTick

`set_invulnerable` 与 `freeze_on_tick` 是两个独立的 `[OP]` action。前者只控制 Boss 无敌，
后者只暂停当前符卡运行时的普通 onTick 时钟。选中无敌节点时，编辑器提供默认关闭的“关联冻结 onTick”
快捷开关；开启后在其后插入普通 sibling 冻结节点并复制无敌时长，关闭后用 `disabled` 保留冻结参数。
导出的 JSON 没有隐藏子字段，两种节点可以独立添加、移动和编辑。

建议把宣言动作放在阶段的 `on_enter` 中：

```json
[
  { "type": "spellcard_init", "health": 600, "duration": 1200 },
  { "type": "set_invulnerable", "duration": 100 },
  { "type": "freeze_on_tick", "duration": 100 },
  { "type": "show_spell_title", "duration": 100 },
  { "type": "ysm_render", "hint": "special=cast+swing_hand", "duration": 100 }
]
```

上述例子同时启动初始化、无敌、标题与 hint。前 100 tick 不推进 onTick；无敌到期后从
`phase_tick = 0` 开始发射。在运行中冻结时，从冻结前的进度继续，不补发冻结期间的波次。

## 命中玩家后执行命令

`on_hit_entity` 的动作可以用 `hit_entity_is_player` 条件区分实际命中的实体。命令动作使用
`hit_context: "as_hit_entity"` 后，命令源实体会切换为这次命中的玩家，因此 `@s` 就是中弹玩家；
命中妖怪、其他实体、方块或没有命中上下文时条件为假，不会执行 `if_true`：

```json
{
  "type": "conditional",
  "condition": { "type": "hit_entity_is_player" },
  "if_true": [
    {
      "type": "run_command",
      "mode": "as_caster",
      "hit_context": "as_hit_entity",
      "command": "tellraw @s {\"text\":\"蕾米莉亚：我的神枪是不可逃避的\"}"
    }
  ]
}
```

把这段放在弹幕或激光的 `on_hit_entity` 分支中即可。`mode: "as_caster"` 保留符卡动作的权限，
`as_hit_entity` 只负责把 `@s` 绑定到实际命中玩家；它不会替代玩家条件判断。

| 内容 | 冻结期间行为 |
|---|---|
| `on_tick`、其中的条件/重复/序列动作 | 暂停；`phase_tick` 与该动作链的 `total_tick` 不前进 |
| 从 `on_tick` 排入的 `delay` / `burst`，包括嵌套延迟 | 保留剩余等待时间，恢复后继续 |
| 并行子符卡、声明式阶段转换 | 暂停随主符卡推进 |
| `on_enter` / `on_damage` 的延迟及显式阶段指令 | 正常执行，可用于主动解除无敌或切换阶段 |
| 已发射弹幕、命中/消失回调与 hold 释放 | 正常推进 |
| 无敌截止时刻、标题/hint 时长 | 以世界时钟正常到期 |
| Boss AI、导航、当前速度 | 正常运行；冻结节点不控制实体移动 |
| 符卡血量时限、HUD、战斗耗时 | 正常计时，冻结不会延长认证/玩家符卡时限 |

同一 tick 已经开始执行的动作列表执行完毕；在 `on_tick` 内开启冻结，从下一 tick 暂停。
放在 `on_enter` 时，首次 onTick 即被冻结。普通阶段切换保留无敌的绝对截止时刻；重置、重新开始阶段、
换符卡或结束后解除。两个节点的 `duration: 0` 分别清除自己的状态，重复设置时也分别替换各自窗口。

无敌只保护实际运行主符卡的 YH 妖怪/Boss，不给玩家或玩家代理授予无敌，也不暂停 AI、导航或移动。
因此只放 `set_invulnerable` 就能制作无敌且继续移动/发射的符卡。冻结期间，Boss 原生移动控制仍运行；
若 `caster_moves` 写在普通 `on_tick` 中，它会随该 action 时钟暂停。编辑器隔离预览可以演示冻结时序。
两个节点的新建默认时长均取 `YHModConfig.COMMON.spellDeclarationInvulnerabilityTicks`，快捷关联仅在首次创建时复制无敌时长。

## 玩家与 Boss 的符卡 hint

原先 `ysm_render` 仅向 `YsmRenderOverrideTarget` 写入，玩家和玩家符卡代理没有这条消费路径，
因此同一 hint 在 Boss/编辑器可播放，在玩家身上会被忽略。

现在按实际施法者投影：Boss 使用自身，玩家符卡使用玩家，挂载型代理使用其显示宿主，
弹幕回调解开 `TrailCardHolder` 后仍指向原施法者。可见的 Shooter 保持自身动画目标，不把 hint 转给伤害所有者。
真实实体共用服务端 hint 状态与同步包，
编辑器继续使用隔离预览时钟。

- 使用当前模型。编辑器 hint 选择器中的模型只用于浏览候选，不替换玩家模型、纹理或装备。
- 共用裸动画名、语义别名和 `special=候选+回退` 的规范化规则。候选区分大小写，按顺序选择真实存在的动画。
  `angry` / `cast` / `charge` / `special` 的优先级与 Boss 外部渲染路径一致；未知分组仍不生效。
- 玩家通过可选 mixin 接入原生 `PlayerBaseAnimationPredicate`，保持 OpenYSM 玩家渲染器、装备层和
  模型切换行为。Boss 仍使用既有 `ExternalLivingRenderAPI` 委托链，第三方源码及其反射签名不变。
- `duration` 使用世界 tick。正值到期清除；`0` 持续到主动清除或来源符卡结束；空 hint 立即清除。
  新 hint 替换旧 hint，旧符卡的清理不会删除新符卡的提示。
- 玩家本人、追踪者以及后来进入视野的追踪者都接收同一截止时刻。取消、换符卡、重置、代理移除、战败
  会清理来源提示；客户端离开追踪、退出或切换世界时清理快照，避免实体 ID 复用或再次进入视野时残留。
- hint 只改变动画。服务端决定时长与作用对象；客户端不修改战斗状态、碰撞、姿态或玩家无敌。
  战败表现和模型切换保留优先级。未装 OpenYSM、接口不兼容或候选动画不存在时使用原有渲染/动画。

不同模型只会播放自身拥有的动画，因此比较双方表现时应绑定同一模型并使用同一 hint。

## 0.29.2 补修：编辑器刷新与动作名称

冻结开关原先调用默认不重建的 `notifySimple`，初始化关联面板也只写入动作数据。
`addBoolRow` 捕获了建行时的布尔值；缺少重建时，按钮文字保持旧状态，再次点击仍提交同一个值。
此前只有下拉选择在控件层保证刷新，普通按钮依赖各处回调；弹幕、激光、条件等更新函数又各自复制重建逻辑，
且默认行为与普通动作不同。

现在动作属性面板使用 `EditorViewRefresh` 汇总刷新请求：

- 开关、普通按钮、整行按钮、删除子项、收藏和下拉选择都经过同一交互入口。
  冻结开关的独立节点与初始化关联面板均在下一帧显示当前状态，连续点击可正常开关。
- 数据更新汇入 `notifySimple`；弹幕、激光、文字弹幕和条件更新只保留类型适配，并支持编辑禁用节点的内部数据。
  普通文本与数值变更不重建输入框，保留光标和输入历史；改变字段结构时仍可显式请求重建。
- 一次或多次回调发出的重建请求在下一次绘制/输入前合并执行，读取最终动作状态。
  不在 Minecraft 控件事件派发中途移除按钮；移除旧控件时清理旧焦点，折叠/删除后限制滚动范围，隐藏标签页的新控件保持隐藏。
- 符卡树的插入、剪切、粘贴、移动、禁用、删除与撤销/重做共用选择、修改标记、弹幕预览 ID 和标题预览更新。
  撤销/重做后，原路径仍存在时重新选中该节点；属性值跟随恢复的数据。键盘和鼠标操作均遵循自动重播开关。
- 替换损坏节点时创建当前节点专用的替换回调，避免复用上一次添加动作留下的回调。

名称的割裂来自三处：添加菜单的名称表、属性标题的名称表，以及节点列表拼接英文后再匹配翻译的摘要。
现在三处都按注册类型调用 `SpellEditorLocalization.actionName`，40 个正式类型均有中英名称，
`set_spell_health` / `bounce` 两个别名复用对应正式类型的名称。新增中文源为 `spell_editor_actions.json`，
英文直接维护在 `en_us.json`；两个语言的文本均通过资源管理器读取，编辑器的中英文切换和资源包重载生效。
用户自定义名称、变量名、动画 token 和资源 ID 保持作者输入。

本次也复核了其他编辑路径：YSM 面板已有控制器 `viewVersion` 和统一重建入口；魔法阵区分结构重建与取值刷新；
Raw JSON 在完整定义替换后恢复阶段和选择，输入错误时保留草稿。它们使用各自的数据模型，
本次收拢的是存在遗漏的动作控件刷新与符卡树操作流程。

## 版本与工程边界

- 版本归入 `2.7.0+HCDRS_0.29.2`。初始化宣言衔接、标题渐变方向和图片目录/缩略图也在本版本交付，
  详细操作保留在 [标题演出说明](0.29.1-remilia-and-spell-title.md)。
- 内部新增 `YsmSpellHintToClient`，客户端与服务端须同时更新到 0.29.2。包注册追加在既有列表尾部。
- 运行时 NBT 新增可选 `FrozenOnTickTicks` / `OnTickFrozenUntil`；`CasterInvulnerableUntil` 独立保存无敌的
  世界截止时刻。缺少冻结字段的旧数据按未冻结读取，延迟队列仍按既有契约不存档。
- 阶段切换后的首次 onTick 使用 `phase_tick = 0`，包括同阶段重入；避免在下一阶段的宣言结束后漏掉第零刻动作。
- 活跃 hint 是符卡执行期状态，不写入永久模型绑定。卸载/重载不恢复已结束的提示。
- 公开 `YHStgApi`、KubeJS 事件、OYSM API 和 TLM 契约不变。新增 mixin 为客户端 `@Pseudo`，
  无强制 OYSM 依赖，不重排法阵 → YSM → TLM → 原版渲染链。
- 上游冲突区需复核模组入口新增的尾部网络包注册、`YHClient` 的编辑器语言重载监听、fork 配置段以及最终版本号；
  `build.gradle`、生成器、第三方源码和内置动画资产不改。中文增量写入 fork 的 `spell_title.json` 分片，
  动作名称使用新增的 `spell_editor_actions.json` 分片；扁平中文由 `organizeLang` 生成，英文手工维护。
