# 0.30.0：AI 辅助编辑与符卡交付

2026-09-13 维护者收缩版本范围：0.30.0 专注 AI 符卡生成和必要的编辑器/战斗入场修复。
结界从 pre2 开始的开发全部标为 aborted，移到 [0.31.0 待重开计划](0.31.0-barrier-development-plan.md)，尚未重开。

## 本轮收尾决定

2026-09-13 维护者决定保留现有游戏内 AI，优先作为已有符卡的编辑助手：辅助公式编写与
计算、数值换算、参数调整和重复节点修改，沿用当前完整 JSON、检查反馈和差异查看流程。
这些操作通过现有修改入口完成，不新增独立计算器或批量编辑协议。

从零设计弹幕的效果偏弱作为已知质量限制记录；新建入口保留，但达到内置 migrated spell
的编排水平不作为本轮收尾条件。模板检索、多帧视觉回修、外部创作包的新入口仍停留在讨论，
本轮不继续扩展。现有功能与缺陷修复按主题独立提交，pre1fix 与 `0.30.0` 同步后结束本轮开发。
