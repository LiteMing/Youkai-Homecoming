# 0.30.3：玩家符卡权限与非符发射 hotfix

0.30.1／0.30.2 的非符检查强制要求碰撞后销毁，与 `fire_danmaku` 的默认 `continue`
行为冲突，导致基础非符无法启用；玩家能力过滤还误伤了 Boss 和预览的旧式发射桥接。
本次恢复基础发射，统一玩家符卡和非符的权限规则，补齐子机链路和权限提示。

## 管理命令

```text
/yhspell permission <玩家或选择器> <0..4>
/yhspell permission <玩家或选择器>
/yhspell permission <玩家或选择器> reset
```

省略数字查询当前等级及来源；`reset` 删除手动覆盖，立即恢复默认等级。命令需要原版权限 2。
数字补全同时显示对应能力说明。

| 等级 | 名称 | 玩家行为 |
| ---: | --- | --- |
| 0 | forbid | 禁用符卡和非符；拒绝新施放并终止当前施放，不扣费、不加冷却。 |
| 1 | base | 执行基础节点；未解锁回调不影响母弹发射。 |
| 2 | hook | 在基础能力上启用命中、消失和轨迹回调。 |
| 3 | EXP | 额外启用实验性节点，包括实验性发射、目标坐标与 Boss on-damage 回调。 |
| 4 | OP | 额外启用 OP 节点；全局 DENY 和不可解码节点仍不可执行。 |

手动设置优先于 OP 默认权限和成就进度，包含手动设置 OP 玩家为 0。权限只过滤当前节点；
子节点独立判断，拒绝的条件节点走 `if_false`。普通符卡、非符、延迟回调、子机和接续符卡
使用相同规则；已发射回调执行时读取玩家当前等级，不能保留旧的授权。

玩家施放显式开启权限过滤。由服务器驱动的 Boss、预览与旧 Java 发射桥接保持原有执行能力。
现有 KubeJS `YHSpellConfig` 玩家／能力权限方法、事件名称和参数不变；
`/yhspell capability get|set` 仍管理全局能力策略。

## 非符检查

`NonSpellValidator` 委托普通符卡分析器，使用共用的结构、寿命和性能检查。
删除非符独有的碰撞终止、反馈白名单、禁用激光／子机、速度、原点、运动器、血量和表现节点限制。
玩家等级决定节点和回调是否执行；基础等级不会因为不可执行的回调输出而被发射额度卡住。

非符额外收紧的预算是当前 Power 下的 `maxSpawnPerTick`：
`(floor(tier / 4) + 1) * (floor(Power) + 1)`，且不超过服务器共用上限。
主循环、延迟回调、子机实体和子机发出的弹幕共用同一世界 tick 额度。Power、玩家权限或
符卡定义变化后重新检查；更新额度不重置本 tick 已消耗数量。非符停用后子机停止生成，
已存在弹幕沿用原有收尾流程。已有开发者非符限流旁路保留。

## 成就与提示

默认玩家为 1，原版 OP 默认为 4。启用 `spellPermissionCardProgression` 时，
`spellcard_tier6` 自动解锁 2，`spellcard_tier12` 自动解锁 3，并发送解锁提示。
Tier 6 的物品条件扩展为 Tier 6–12 任意阶级，保留 `has_tier6` 存档条件名。
原有时符灵气和终符灵气奖励保留，成就说明写明权限奖励；禁用自动进度或存在手动覆盖时不自动升级。

补齐 `youkaishomecoming.tooltip.spell_permission_limited` 的英文运行时文本和中文分片源，
并增加禁用、解锁、命令反馈及五级权限的双语文案。权限 0 提示覆盖内置符卡与动态符卡；
空回调和禁用节点不再产生虚假的权限不足提示。中文运行时文件由 `organizeLang` 生成。

## 兼容性与合并复核

本次包含仓库内部破坏性调整：删除旧 `/yhspell permission list|get|set|group|player ...`
语法，改为上面的玩家直设命令；删除 `nonSpellMaxLifetimeTicks`、`nonSpellMaxInitialSpeed`、
`nonSpellMaxOriginOffset`、`nonSpellMaxHookExecutions` 四项专用配置。旧 TOML 项不再生效。
玩家权限存档字段、已达成成就和公开脚本签名保留。客户端与服务端应一起升级至 0.30.3。

改动集中在本 fork 的权限、分析器、玩家发射器、子机和现有命令／语言增量。
已登记的上游合并点中仅运行时语言资源及最终版本号有变更；`build.gradle`、
`BulkDataWriter`、模组入口、语言生成器和第三方兼容源码不变。
