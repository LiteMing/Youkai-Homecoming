# 0.30.4：非符生命周期与弹幕战入口 hotfix

`0.30.3` 将非符大部分检查统一到普通符卡分析器时，也移除了非符不能声明
`spellcard_init` 的生命周期约束。含该节点的非符会走符卡血条和有限时长代理路径，
破坏非符的持续释放、再次按键停用和已有弹幕收尾，表现为启用后立刻取消。

## spellcard_init 约束

非符现在绝对禁止启用中的 `spellcard_init`，包括阶段的四个动作列表以及
sequence、conditional、repeat、delay、burst 等嵌套位置。禁用节点不执行，因此不算声明。
普通符卡继续支持该节点。

约束在以下服务端边界统一执行：

- 玩家保存和市场导入非符定义；
- 动态符卡施放、创建玩家代理之前；
- 非符代理运行中切换到另一份定义时；
- Power／权限变化后的普通非符重新校验。

`/yhdev bypass_spell_limiter` 只旁路性能分析与单 tick 发射额度，不能旁路这条生命周期约束。
拒绝时显示独立的中英文原因，不再落入笼统的结构检查提示。

编辑器根据即将绑定的空白卡类型创建定义。非符首阶段不再自动插入
`spellcard_init`，添加节点菜单也不再显示它；普通、时符和终符仍保留原默认初始化。
服务端以已绑定卡优先，其次按主手、副手、背包顺序读取空白卡类型，避免背包里的另一张
普通空卡覆盖手中非符基底的类型。

## 空白非符基底

非符灵气可在铁砧中直接应用到没有 `spell_id` 的动态符卡基底。输出仍为空白卡，等待玩家
命名并创建定义；阶级、草稿预算和其他模组 NBT 原样保留，输入物品不被修改。

完整卡、认证卡和带 EX 特征的基底仍不能转换成非符。时符、终符及 EX 灵气继续要求
已经绑定的未完成定义，避免扩大本次修复范围。JEI 的非符灵气示例同步改为空白基底。

## 弹幕战入口与经验

Shift+F 和 Shift+右键此前复用了场外符卡施放的支付预检。默认场外价格为 5 级经验，
因此它意外变成了弹幕战的隐藏入口门槛。

0.30.4 将入口资格与实际施放费用分开：在战斗外，只要持有完整、未损坏的普通／时符，
或冷却就绪的终符，即可进入弹幕战，不检查也不扣除 XP。进入后仍按 Bomb 余额选择和施放
符卡；直接在战斗外施放仍按原规则消耗 XP。整合包需要额外成长门槛时，可在脚本或进度层
另行控制，不再由模组本体隐式绑定到经验数额。双语快捷键提示明确写出“进入不消耗经验”。

## 验证

- `SpellPermissionHotfixTest`：117 条断言，覆盖直接／嵌套初始化拒绝、禁用节点、普通符卡兼容及编辑器默认定义。
- `SpellDraftRecoveryTest`：43 条断言，覆盖空白非符转换、NBT／预算保留、输入不变及认证／完整卡保护。
- `SpellCombatEntryTest`：49 条断言，覆盖零 XP 进入、场外实际施放 XP 预检、战斗内 Bomb 预检和终符规则。
- `compileJava`、`compileTestJava` 与 `organizeLang` 通过，共 209 条定向断言通过。

这些检查不启动游戏客户端，不能代替 Shift+F、Shift+右键和持续非符的实机验收。
