# YSM 默认绑定配置

0.30.8 将跨存档的 YSM 默认外观从 Java 硬编码抽成配置。默认配置资源位于
`assets/youkaishomecoming/yhysm/defaults.json`；资源包可以用同一资源路径提供自己的默认映射。

整合包作者也可以在实例的
`config/youkaishomecoming/ysm_defaults.json` 中追加或覆盖映射。该文件在客户端资源重载时读取，
修改后按 `F3+T` 重新加载资源即可生效。它是类型级绑定的持久配置来源；编辑器保存类型时会更新
此文件。单实体 UUID 绑定仍写入当前存档，并优先覆盖类型配置；预设文件 `ysm_presets.json` 不会被改写。

配置可以同时声明实体绑定和模型表达式规则：

```json
{
  "entities": {
    "othermod:entity": {
      "model": "otherpack/model",
      "texture": "default"
    }
  },
  "models": {
    "otherpack/model": {
      "expressions": {
        "angry": ["angry", "attack"]
      }
    }
  }
}
```

`entities` 的值支持 `enabled: false`，用于明确关闭某个默认绑定；省略 `texture` 时使用
`default`。`models` 的表达式候选按数组顺序尝试，模型没有该规则时继续使用 YH 的通用回退链。

YSM Editor 的实体类型和模型输入会合并当前运行时目录、共享预设以及这份配置中声明的 ID，
因此可以先编辑尚未在当前世界加载的模型或实体类型。模型资源仍由 OYSM 提供；配置只负责默认
跨存档映射和表达式候选。

命令行绑定时，类型目标使用配置层，单个实体使用当前存档：
`/yhysm set <UUID> model <model> [texture]`。UUID 绑定取消后会重新使用该实体类型的配置映射。
