# YH 0.34.0 / OYSM HCD 0.4.0：统一模型入口

编辑器、绑定和符卡中的模型字段可直接选择 `youkaishomecoming/remilia/main`、
`youkaishomecoming/remilia/trident`、`youkaishomecoming/remilia/ender_pearl` 等完整路径。
所有模型选项共用 OYSM 的入口目录，包括 shooter、施法者预览、实体绑定、弹幕和激光。
主模型、arm、模型包声明的投射物、vehicle 几何均可枚举；不存在的 arrow 不会被添加。

Shooter 保留 LivingEntity 的血量、移动、目标和发射逻辑，渲染可选择 projectile 入口；
弹幕和激光也可选择 main。激光模型仍绘制在光束起点，原光束与碰撞路径保留。
模型路径沿用原有覆盖字段与同步/存档链，不添加第二份包/入口同步状态。

## 配置与兼容

```json
"ysm": {
  "model": "youkaishomecoming/remilia/trident"
}
```

```json
"ysm_projectile": {
  "model": "youkaishomecoming/remilia/main",
  "model_scale": 1.0,
  "max_instances": 8
}
```

模型配置使用完整入口路径；旧的包名和 slot 形式不属于当前契约。
弹幕/激光编辑器显示完整入口，移除重复的 Projectile Slot 下拉；选择新路径时清空旧 slot 的选择。
投射物入口不继承 main 的预设、动画列表和控件；preset ID 由 OYSM 注册 API 返回，YH 只使用返回值。

YH 仅负责实例预算、方向修正、偏移和颜色，直接把真实弹幕实体交给 OYSM；
删除旧的临时箭/三叉戟实体适配。选模与模型生命周期归 OYSM。
OYSM 原生 preset 服务和 editor 是唯一实现；YH 只提供资源、默认定义和业务绑定。
