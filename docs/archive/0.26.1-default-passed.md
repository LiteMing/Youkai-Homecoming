# 0.26.1 默认验收归档

本文件归档 0.26.1 已通过的功能验收项。后续开发以当前实现和提交历史为准；未列入本文件的内容不视为已完成。

- Hold 使用回调 `SpellContext` 携带的 holder/runtime/definition，不再从真实玩家 projectile owner 反向猜测 Runtime。
- Hold 在源 Runtime cast loop 结束后仍可释放；DataDrivenTrailAction 使用统一 `executeList`，命中回调遵循 Last Writer Wins。
- Bounce、Hold、反序列化回调和删除路径具备服务端诊断覆盖。
- 动态草稿不会进入弹幕战；草稿编辑、复刻持久化和认证边界已接入。
- 非符使用玩家服务端 P 点，并按 `(floor(tier / 4) + 1) * (floor(power) + 1)` 限制每 tick 发射量；普通符卡保留历史 `128 * tier` 上限。
- 符卡节点能力可按 origin、size、lifetime、target_xyz、tracking mover 等规则分类，并支持配置/KubeJS 覆盖。
- 特殊符卡类型和灵气转换逻辑已实现：非符、时符、终符及 EX 灵气的类型、认证和经验规则已接入。
- 复刻符卡完成后的 UTF-8 原子保存、旧 Windows 编码迁移和物品栏同步已覆盖。
- 动态符卡 GUI、卡面快照和符卡边框持久化路径已接入；Exposure 保持 1.7 稳定版兼容。
- `run_command` 客户端预设、服务端执行和权限边界已接入。

验证基线：`compileJava`、`organizeLang`、`runSpellAnalyzerSelfTest`。实机战斗、渲染和第三方组合仍需按发布门槛单独复测。
